# 登録済み情報源一覧を閲覧する (List Sources)

## 目的・概要

投資家がシステムに登録している `Source`（情報源）の一覧と、それぞれの取得ステータスを確認する。情報収集パイプラインが正常に稼働しているか、どのスコープ（企業/業種/テーマ/マクロ/市場）から何を得ているかを管理するための画面。

## 事前条件

- なし

## 事後条件

- なし（参照のみ）

## 基本フロー（正常系）

1. 投資家は「情報源の管理（Source 一覧）」へのアクセスをリクエストする。任意で `layer` や紐づく `Company` / `Sector` / `Theme` による絞り込み条件を指定する。
2. システムは、条件に合致する `Source` を取得する。
3. システムは、各 Source の情報（表示名、URL、種別、`layer`、紐づく参照先、`status`、`lastFetchedAt`）を一覧として投資家に提示する。

## 代替フロー・例外フロー

- **2a. 登録されている Source が0件の場合:**
  システムは空のリストを表示し、新しい Source を登録する（[Register Source](../register_source/usecase.md)）ための導線を提示する。
- **3a. 取得エラーが続いている Source がある場合:**
  `lastFetchedAt` が古すぎる、あるいは内部的にエラーが記録されている場合、システムは一覧上でその Source に警告アイコン等を表示する。
