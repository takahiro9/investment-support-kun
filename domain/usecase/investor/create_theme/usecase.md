# テーマを作成する (Create Theme)

## 目的・概要

投資家が、単一の `Sector` に閉じない、複数業種を横断して影響する業界動向・政策・社会動向を `Theme` として登録する。1つの政策ニュースが複数銘柄の `Thesis` に影響しうる場合に、その `Source`/`Finding` を特定の `Sector` に紐づけず、`Theme` として独立に扱えるようにする。

## 事前条件

- なし

## 事後条件

- 新しい `Theme` がシステムに保存されること

## 基本フロー（正常系）

1. 投資家は、テーマ名（`name`）と、任意で補足説明（`description`）、このテーマが影響する `Sector` 群（`sectorIds`）を入力し、作成をリクエストする。
2. システムは、`name` が空文字列でないことを検証する。
3. システムは、新しい `Theme` エンティティを作成し、保存する。
4. システムは、作成完了を投資家に通知する。

## 代替フロー・例外フロー

- **2a. `name` が未入力の場合:**
  システムはエラーメッセージを返し、入力を促す。
- **1a. 特定の `Sector` に限定されない、より広いマクロ動向を登録したい場合:**
  投資家は `sectorIds` を空のまま作成できる。
